# 设备与环境档案

设备事实写在**当前打开工作区**的 `mobile-test/devices.md`，不写入 skill。档案用于减少重复发现，**不是永久可信配置**。每次开测先用命令确认连接、App 版本、网络与登录态；验证后更新“最近验证”。不要保存账号密码、GA 码、私钥、助记词、token 或完整页面源码。

## 新设备记录模板

```text
设备代号：
平台 / 型号 / 系统版本：
连接节点（Windows / Mac / 云服务）：
设备 ID（ADB serial / iOS UDID）：
连接方式与发现命令：
App 包名、版本、安装状态：
驱动与客户端版本：
会话地址与专用端口（只记录非敏感配置）：
当前入口页 / 登录状态 / 人工验证要求：
稳定定位符与已验证冒烟 case：
网络与测试环境要求（不含凭据）：
已知阻塞及绕过方式：
最近验证时间、验证人/会话：
```

## 每次运行追加一条简短记录

`日期时间 | case ID | 设备代号 | App 版本 | 入口状态 | 结果 | 报告/截图路径 | 新发现`。该记录写到工作区的对应运行目录，不写进 skill。

设备号可复用，端口不能冲突；使用同一个账号并行时，先确认服务端数据隔离。屏幕坐标按设备分辨率与缩放重新测量，不从旧设备拷贝。旧记录有时效，遇到与现场不一致时以现场为准并更新工作区档案。

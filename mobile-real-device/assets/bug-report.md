# 真机缺陷报告模板

> 发现真实问题时复制到**当前打开工作区**的 `mobile-test/bugs/<bug-id>/bug.md`，同时保存当时截图。环境阻塞和定位符错误单独记录，不直接标为产品缺陷。

## 基本信息

- 缺陷标题：
- case ID / 运行批次：
- 发现时间（含时区）：
- 平台、设备型号、系统版本、设备代号：
- App 包名、版本、构建号：
- 测试环境、网络类型：
- 严重程度与影响范围：

## 复现

1. 前置条件（账号类型、必要数据、入口页；不写凭据）：
2. 操作步骤：
3. 预期结果：
4. 实际结果：
5. 复现次数 / 总尝试次数：

## 证据与结论

- 失败当时截图路径：
- 可选视频 / 经脱敏的日志路径：
- 排除的环境或数据因素：
- 设备是否可继续使用：
- 状态：待确认 / 已复现 / 已修复待回归 / 已关闭

分享前检查截图和日志，不泄露密码、验证码、token、私钥、助记词及真实用户资料。
